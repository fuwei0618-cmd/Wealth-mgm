# Wealth-mgm

給理財顧問使用的高資產客戶財富管理系統（網頁版，手機瀏覽器也可使用）。

## 功能

- **客戶總覽**：客戶數、管理資產總額 (AUM)、需再平衡客戶數、7 天內待聯絡客戶；可搜尋與排序
- **資產配置**：每位客戶的股票、基金/ETF、債券、保險、不動產、現金部位，以圓環圖顯示
- **再平衡建議**：實際配置對比目標配置，偏離超過門檻（預設 5 個百分點）時標示，並算出各類別建議買進／賣出金額
- **風險屬性**：保守型／穩健型／積極型，各有預設目標配置，可逐項調整
- **客戶紀錄**：負債、淨值、下次聯絡日、會談備註
- **備份**：匯出／匯入 JSON

資料只存在使用者瀏覽器的 localStorage，不會傳到任何伺服器。首次開啟會載入三位虛構的範例客戶。

## 開發

```bash
npm install
npm run dev     # 本機開發
npm test        # 單元測試
npm run build   # 產出 dist/，可部署到 GitHub Pages 或任何靜態主機
```

技術：Vite + React + TypeScript，圖表使用 Recharts。
