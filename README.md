# Wealth-mgm

理財觀念剪報：理財顧問向客戶說明「我在為你做的事」的網頁（手機瀏覽器也可使用）。

## 功能

- **觀念剪報**：13 則財務規劃觀念，每則都有「故事版」（說給客戶聽）與「專業版」（架構、公式、數據）兩種說明，可一鍵切換
- **試算工具**：退休所需資產（4% 法則）、本金與報酬率比較、費用成本試算，部分剪報內也直接附上試算
- **我的剪報**：自行新增剪報（存在瀏覽器本機）
- 規劃中：CFP 客戶財富管理流程

內容整理自王伯達《人生財務規劃學》課程逐字稿，每則剪報標示出處單元。

## 開發

```bash
npm install
npm run dev     # 本機開發
npm test        # 試算公式單元測試（以課程範例數字驗證）
npm run build   # 產出 dist/，可部署到 GitHub Pages 或任何靜態主機
```

技術：Vite + React + TypeScript。
